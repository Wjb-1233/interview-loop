## 本轮发现并修复

1. **后台新增场景、微课在 MySQL 上保存失败。** 原生成 ID 加前缀后超过 `VARCHAR(36)`；改用模型统一的 UUID 默认值，补充字段长度断言。
2. **快速完成计划后复测被误判过早，错题再练未被识别。** MySQL 原 DATETIME 丢失微秒，和 JSON 中带微秒的完成时间不一致。统一业务时间为 MySQL `DATETIME(6)`，增加迁移 `20261124_0052` 和真实数据库往返精度测试。原数据保留，旧秒值补零。
3. **数据库完整回滚失败。** 多处旧迁移先删除了外键依赖的索引；删除整张表时改由数据库一起清除索引、外键，保持其他表的索引操作。
4. **真实模型的复杂报告被截断后误触发降级。** 四维证据、建议和专业能力矩阵超过原来的小 JSON 输出预算，评分及一致性复核单独使用 5000 token 上限；其余短请求保持原预算。未尝试补造截断 JSON。[官方 JSON 输出说明](https://api-docs.deepseek.com/guides/json_mode/)也要求为完整 JSON 预留合理输出长度。
5. **单条空证据导致整轮证据观察降级。** 丢弃格式无效的单条观察，保留其余合法记录；原话逐字匹配检查仍然保留。
6. **兼容部分模型响应的额外 JSON 转义。** 有限解码额外封装，保留原有引号与路径，不静默修补损坏、截断的结构；新增正常、Markdown、额外封装、额外转义及无效输出测试。
7. **实时转写完成事件的字段兼容。** 语音/视频房间同时支持 `transcript` 和实际豆包协议返回的 `text`；没有中间 delta 时也能保留已完成回答，新增浏览器回归。
8. **冒烟脚本过时。** 移除对已下线演示登录的依赖，补充注册隐私确认，修复 API-only 地址重复拼接，测试结束自动删除自己的临时账号。

## 复测入口与边界

默认后端回归仍使用自动清理的临时 SQLite。显式提供 `CAREER_TEST_DATABASE_URL` 可跑 MySQL：只接受本机 `career_coach_test_` 开头的数据库及 `cc_test_` 测试账号，开跑前重建该测试库；不能填业务库。`CAREER_TEST_REDIS_URL` 应指向专用测试 Redis。MySQL 的同步测试会隔离跨事件循环的连接复用；实际 API 仍保留原连接池。
