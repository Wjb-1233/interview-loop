## 2. 回归中发现并解决的问题

1. **文字同题比较偏移错误**：此前按 AI(n) 找 USER(n) 对应题，文字实际回答的是 AI(n−1)。通过统一问答契约修正；三通道以及跨通道同题比较均覆盖。
2. **初始化期间注销漏清理**：外壳先于首次路由显示，立即点退出可能拿不到训练 ID。现在等待初始路由就绪后挂载，退出仍先清理再清认证；保留立即点击的回归用例。
3. **旧语音链接兼容**：内部改名时误改了查询键，验收中恢复原 `mode=voice`，增加浏览器回归防止复发。
4. **重复消息的两套资格判断**：同时间戳、同轮重复消息必须以相同的首条问答为准。Python 与 SQL 统一稳定顺序，新增 TEXT/VOICE/VIDEO × AI/USER 六项契约测试；正常原证据仍计入，指向后续重复消息的证据不会混入看板。

这些修复没有重算历史成绩。无对应问题或有效证据的历史报告继续展示为参考结果。
