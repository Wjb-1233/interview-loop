# 功能升级与验收

## 使用流程

1. 场景训练包含公共场景和我的场景；从卡片选择文字、语音或视频。
2. 准备弹窗可上传 docx 简历、填写目标岗位 JD；实时面试可选 5/10/15/30/60 分钟。仅支持中文。
3. 三种方式都保存准备背景。语音引擎由部署配置 VOICE_ENGINE 自动选择，普通学员无需选择实现方式。
4. 完成面试查看四维原句证据与专业内容核查。知识题、方案题、动机题、经历题使用不同信息完整标准。
5. 能力提升依次完成复盘确认、提交一题改写、学习微课并通过练习、同条件复测。计划页显示四维前后分数和提升判定。
6. 微课文字版可独立学习，视频按需生成；学习完成与练习通过分别记录，只有练习通过才完成课程任务。
7. 话术优化允许新用户直接输入原话和背景，无需先产生错题。话术库统一管理全部版本与收藏；收藏场景从场景入口访问。
8. 管理端在“场景设计”统一维护场景和题目，支持搜索、题目维度/难度及 JSON 导入导出，每个场景最多 20 题；移除重复题库管理页。微课底稿在“微课内容管理”维护，覆盖新增、编辑和启停，统计页命名为“题目与错题统计”。
9. 成长看板分开显示全局练习量和同条件成绩。默认自动匹配最近训练的方式、场景、强度、简历与 JD；展示最近成绩、近最多 5 次均分和最多 20 条同条件记录，少于 3 次不展示趋势。提升计划、复测对比与原话证据从能力提升及报告页面访问。详细规则见 [成长看板统计口径](成长看板统计口径.md)。
10. 界面仅面向桌面浏览器，采用桌面导航和布局，最低宽度 1200px。静态资源仅提供网站图标与应用构建产物；`npm run build` 包含资源和凭据检查，`npm run check:build` 可单独复查构建结果。

## 比较边界

报告比较同场景、方式、强度、模式、语言、简历和 JD 的历史正式评分。降级评分保留报告，排除正式成长统计；计划比较有降级结果时标记待确认。
专业内容核查是模型意见；无法确定的内容标记待核实，不宣称已有外部知识库验证。

## 数据升级

先启动 Docker Desktop 并确认 MySQL/Redis 健康；在 backend 中执行 `.venv\Scripts\python.exe -m scripts.upgrade_product`。脚本先将受影响表备份到根目录 backups，再应用迁移。
新增迁移 20261112_0046 删除已下线的故事库、简历诊断、群面、编程笔试四张表；回退可恢复表结构，不能恢复其中旧记录。主面试、简历上下文、评分、计划与话术表保留；话术场景字段改为可空以支持独立改写。回退到旧结构会删除没有场景的独立话术，需从备份恢复。
历史迁移保留。历史未完成计划会补充关联原场景的复测任务。
开发数据服务现为 MySQL 和 Redis；原向量检索及其配套容器不再纳入运行编排。已有容器卷不自动删除。

## 验收重点

- 新用户独立改写并收藏。
- 三种训练方式使用相同准备字段，验证他人不能读取准备资料。
- 复盘、改写、文字微课、课程练习、复测可以完成一整份计划。
- 不同强度、训练方式或背景不直接比较；降级结果不混入正式趋势。
- 升级、回退迁移与前端构建通过。
