| 流程 | 原问题 | 修复后的行为 |

| 语音问答保存 | 把下一题当作本轮回答对应的题目，影响评分依据 | 先保存原题与本轮回答，再更新下一题；覆盖两种语音协议 |
| 实时录制结束 | 未等待录制器最后一段数据，上传可能缺少收尾内容 | 等待录制停止事件后再构造上传文件 |
| 语音评分重试 | 保存成功而评分失败后重复上传；重复保存报错 | 保存重试按同一会话及相同问答返回原记录，评分失败可单独重试；不同内容仍拒绝覆盖 |
| 登录后的公共链接 | 已登录用户打开邮箱验证、重置密码或分享页被重定向 | 允许访问这些公共页面；验证成功刷新用户信息 |
| 话术收藏和筛选 | 收藏按钮状态不同步；切换筛选后可能停在空白页；已解决项入口不可见 | 同步生成结果与列表状态，校正页码，保留筛选入口 |
| 话术库历史版本 | 服务端只返回最近 50 条，旧版本无法从界面找到 | 返回用户完整版本列表，由现有界面分页 |
| 删除计划的原训练 | 复盘区退回其他已评分训练，可能显示无关报告 | 保留计划，显示原记录缺失提示，禁用依赖原记录的操作并引导新训练 |

## 话术库按钮问题补查

- 错误：点击试听后长时间没有反馈，收藏等请求也可能超时，页面误报“大模型处理超时”。
- 预期：试听等待时收藏、删除仍可使用；播放与等待应有明确状态。
- 原因：异步接口直接运行同步语音合成，阻塞事件循环；缓存只检查 WAV，实际生成的 MP3 每次重新合成。不同请求还共享同名中间文件，前端忽略了浏览器播放失败。
- 修复：合成转到工作线程并设置 25 秒响应期限；缓存兼容 MP3/WAV，使用独立临时目录，短试听整段合成。两处话术页面共用播放逻辑，补充生成/停止状态、重复点击保护、播放失败提示和离页清理；收藏成功清除旧错误。
- 防止回归：新增 6 项后端用例，覆盖慢试听期间收藏/删除、两种缓存格式、并发文件隔离、提供商故障和响应超时。新增 3 项浏览器用例，覆盖等待状态、独立操作、播放失败及离页停止。

补查结果：238 项后端完整回归通过；新增 3 项 Edge 浏览器验收通过；TypeScript/Vite 构建通过。当前开发服务实测缓存试听约 0.02 秒返回，新语音约 2.9 秒生成；语音生成期间健康接口约 0.01 秒响应。系统 Edge 已使用真实 MP3 验证页面中的播放启动和停止，未出现页面异常。此项只验证话术朗读，不代表实时面试语音 WebSocket 已实机验收。5173 前端与 8081 后端保持运行。

## 历史微课不能回看

问题：已生成过的历史微课重新打开仍提示生成视频。本机 3 个已有文件中，2 个使用降级渲染的 `-remotion-python` 文件名，原接口却只查配置引擎的文件名；非模型生成、尚未开始学习的课程还可能在重新打开时被自动改写，改变原视频内容键。视频状态 GET 也会生成课程，不能保证只读。

修复：计划保留已有课程快照，只有明确换课才更新内容；视频生成成功后，将实际视频键与课程内容键一起保存到课程任务，后续学习进度更新继续保留。回看查询只读取，不生成课程或视频；兼容现有 remotion、python、降级及旧文件，配置切换也能找回已保存的视频。主动换课清理旧关联，不删除原文件。前端区分正在读取、读取失败和确实没有视频，提供重新加载入口；换课后清除旧播放器，离页清理请求和计时器。

验证：回归先复现 8 项失败、1 项通过；修复后相关后端 14 项、完整后端 259 项、新增浏览器 4 项及 TypeScript/Vite/资源校验通过。浏览器覆盖已完成计划回看、视频实际播放与章节跳转、返回和刷新不生成、首次生成后复用、查询失败重试与换课清理旧视频。

本机实测 3 个原视频全部找到并返回 HTTP 200，课程内容及学习记录没有被查询改写。现有学员的一份约 99.9 秒历史视频可以播放、拖动并刷新复用，重新生成请求为 0，无页面异常。校验时发现原后端已停止，已恢复 8081 服务，5173 前端保持运行。截图：`docs/evidence/course-replay-desktop.png`。
