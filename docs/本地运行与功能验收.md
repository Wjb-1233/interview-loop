# InterviewLoop 本地运行与功能验收

如果希望尽量不用终端，请先看[网页版启动指南](启动指南.md)，按 PyCharm 和 Docker Desktop 的界面操作。本文保留命令行步骤作为备用。

本地完整环境使用 MySQL 保存用户、会话、评分和训练计划，Redis 负责限流。大模型 API 生成对话、话术改写和评分，Vue 开发服务器代理 FastAPI 接口。SQLite 和内存限流可用于本地测试，模型不可用时可通过本地教练模板继续基础对练。

## 一、启动数据服务

在项目根目录复制配置并启动服务：

```powershell
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
docker compose --project-name career-coach up -d
docker compose --project-name career-coach ps
```

在 `.env` 中填写 `LLM_API_KEY`。等待 MySQL 和 Redis 显示 healthy 后，再启动后端。
Docker MySQL 使用本机 `3308`，Redis 使用本机 `6380`，避免和已安装的服务冲突。

## 二、在 PyCharm 中启动后端

1. 用 PyCharm 打开仓库下的 `backend/` 目录。
2. Python 解释器选择 `backend/.venv/Scripts/python.exe`。
3. 新建一个 **Python** 运行配置，并把启动目标从 **Script path** 切换为 **Module name**：
   - Module name：`uvicorn`
   - Parameters：`app.main:app --host 127.0.0.1 --port 8081 --reload`
   - Working directory：仓库下的 `backend/` 目录
4. 点击运行，控制台出现 `Application startup complete` 即成功。
5. 浏览器打开 `http://127.0.0.1:8081/docs`，能看到 Swagger 接口页面即可。

如果 `.venv` 尚未创建，请从项目根目录执行下面的命令：

```powershell
# 从项目根目录进入后端目录
Set-Location .\backend
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install --constraint constraints.txt --requirement requirements-dev.txt
.venv\Scripts\python.exe -m alembic upgrade head
```

## 三、启动前端

另开一个终端执行：

```powershell
# 从项目根目录进入前端目录
Set-Location .\frontend
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`。

可直接使用：

- 学员：`student@example.com` / `Student123!`
- 管理员：`admin@example.com` / `Admin123!`

## 四、验证训练流程

1. 使用学员账号登录。
2. 按面试类型、行业、岗位和难度筛选一个面试场景。
3. 创建训练并至少完成 2 轮对话，生成初次评分。
4. 查看系统生成的回复建议和四维评分。
5. 打开薄弱项计划：三张任务卡分别是场景再练、视频面试、个性化微课；先读复盘批注，再完成微课三步与表达练习（点「看视频版」看动画讲解）。
6. 回到原场景新开一轮会话（至少 6 轮），验证复盘批注里的问题是否改掉。
7. 回到报告页对比四维前后分数与提升判定；在「话术优化」里把改写后的句子试听一遍。
8. 打开成长看板查看历史综合分和四维趋势，也可进入训练记录回看对话或导出 CSV 报告。

微课作答与改写必须经大模型评价通过；离线时只保存为“待评价”，不计作完成。验证完整流程需要可用的大模型 API Key。

## 五、大模型 Key

推荐直接写入项目根目录的 `.env`：

```dotenv
LLM_API_KEY=你的Key
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-chat
```

不要把 Key 写入代码或截图。模型接口临时不可用时，可通过本地模板继续基础对练。

## 六、常见问题

- 后端提示端口占用：把 `8081` 改为其他端口，同时修改 `frontend/vite.config.ts` 的代理地址。
- 前端提示 `npm` 不存在：重新安装 Node.js，并勾选加入 PATH。
- 后端提示缺少模块：确认 PyCharm 使用的是项目 `.venv`，然后重新安装依赖。
- 页面能打开但请求失败：先确认后端控制台仍在运行，并访问 `http://127.0.0.1:8081/docs`。
- MySQL 或 Redis 连接失败：先在项目根目录运行 `docker compose --project-name career-coach ps`，确认对应服务为 healthy。
- 大模型一直使用本地模板：检查 `.env` 中的 Key、接口地址和模型名，修改后重启后端。训练页与报告页会明确标出是否降级。

## 七、运行检查清单

- 后端能够启动，Swagger 能打开；
- 前端能够启动并登录；
- 至少四个内置面试场景都能创建训练；
- 对话能够返回内容并生成四维评分；
- 模型 API 可用时，训练报告显示正式评分；
- 训练计划和成长看板能够显示。
