# 评分与成长统计修复

## 三项修复

1. 待重评的报告退出正式统计。修改转写后，旧分数不再进入成长看板的比较分组、均分、趋势、四维表现及训练总结，也不作为其他报告的历史基线。已完成训练次数继续保留。
2. 历史比较按训练发生时间排序。旧训练后来重评，不会将之后完成的训练当成“上次”。重评成功后保留上一版分数、总评、建议与原话证据，报告 ID 不变；重评失败时原报告不丢失，页面可继续查看及重试，不会额外生成提升计划。
3. 四维证据不足的模型报告明确标记为参考分数。接口返回评分状态、缺失证据维度及是否参与成长统计；报告页、教练分享页和独立导出报告同步展示说明。点击“补充评分依据”才发起重评，打开报告和看板不会自动调用模型。
