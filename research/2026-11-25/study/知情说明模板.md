# 参与说明与记录模板

这是一份待研究负责人完善后使用的模板，当前没有任何人签署。

目的：了解面试训练工具的可用性与训练前后表达变化。流程包括三次四题作答和约 15 分钟训练；总时长以实际安排说明。评分仅用于评估训练工具和表达变化。

默认采用文字作答，记录匿名编号、作答原文、评分、训练时长与必要的运行问题。不要在回答里提供真实企业保密内容或身份联系方式。若另行录制声音或视频，应在开始前说明并单独获取同意，文字同意不代表录音录像同意。

参与是自愿的，可以随时暂停或退出。说明退出后的数据删除方式、负责人联系方式、存储位置、访问人员和保留期限后，再开展采集。公开展示匿名原话前，应确认展示范围并单独取得授权。

| 待填写项目 | 内容 |
|---|---|
| 负责人及联系方法 | 待填写 |
| 预计流程与总时长 | 待填写 |
| 数据存储位置、访问者、保留至何时 | 待填写 |
| 退出与删除数据的方法 | 待填写 |
| 参与者匿名编号 | 待填写 |
| 已说明目的和流程；同意参加 | 待确认 |
| 是否同意公开展示匿名原话 | 单独确认 |
| 日期及实际确认方式 | 待填写 |

协调人在实际取得同意后，才在运行目录的 participants.csv 填 YES。不要预填同意或编造参与者。
