# 设备、网络与并发验收

本材料区分三类证据：真实设备手工验收、浏览器受控事件回归、受控上游的负载工具检查。后两者不能替代真人麦克风、摄像头或真实模型的质量与容量结论。

## 真实设备清单

复制 device-checks.csv 到运行目录后填写。当前所有手工项为 NOT_RUN。建议至少在 Chrome 和 Edge 各跑一轮，记录浏览器版本、设备、系统、实际现象和日期。

| 场景 | 操作 | 验收点 |
|---|---|---|
| 允许权限 | 开启麦克风/摄像头，回答两题 | 有音量反馈、面试官可听见，视频画面正常 |
| 拒绝权限 | 拒绝麦克风或摄像头 | 明确提示和重新申请入口，可切换合适的训练方式 |
| 设备占用、拔出 | 其他程序占用后进入；作答中拔掉耳机/摄像头 | 显示可恢复错误，不白屏、不重复保存 |
| 静音、背景噪声 | 安静、静音、旁人说话或风扇声分别试验 | 不凭空产生回答；保存前能在报告核对和修正转写 |
| 弱光 | 降低环境照明 | 画面提示真实；不把画面质量误当表达能力 |
| 断网、恢复 | 面试中断网再恢复 | 能理解状态、重试或退出；不会误提示评分成功 |
| 提前结束 | 第一题说完后立即结束，面试官尚未回复 | 按已有回答总结，不丢最后一句、不评价未作答题 |
| 直接退出 | 作答后点直接退出 | 不保存报告或音视频；准备会话被丢弃，设备停止 |
| 打断、重听 | 面试官说话时打断、重听 | 不重复出声；本地形象回退后语音仍正常 |
| 数字人不可用 | 断开上游或阻断人物资源 | 回退本地形象；回答、结束和评分入口仍能使用 |
| 微课回看 | 打开旧计划中已生成的视频，刷新再打开 | 直接播放已有资源，无需重新生成 |
| 关闭与返回 | 面试中离开页面再返回 | 摄像头指示灯和音轨结束，不残留旧连接 |

不能自动启动真实摄像头或麦克风来替人验收。手工测试前由测试者主动授权。建议使用自己编写的虚构项目回答，避免录入不必要的私人内容。

## 受控浏览器回归

前端 `e2e/video-immersion.spec.ts` 覆盖两种语音协议、隐藏转写、末句保存、权限异常、直接退出、打断和形象回退；`avatar-config.spec.ts` 覆盖配置优先级。测试使用合成音轨和模拟协议，不是实际设备识别率测试。

在本机 API 和 Vite 启动后执行：

```powershell
npm.cmd --prefix frontend run e2e -- video-immersion avatar-config functional-repairs desktop
```

涉及“正式模型报告”的浏览器用例需要可用模型。没有额度时可在**独立测试数据库**中使用 `backend/tests/support/llm_stub.py` 提供确定响应；不能将其指向业务环境，或把该结果称为真实评分准确率。

## 并发工具

使用独立测试环境和短期测试账号。账号/令牌文件仅放忽略目录，每个虚拟用户尽量用不同账号。工具只丢弃自己创建的训练会话，不删除已有账号；测试者管理专用账号。

```powershell
# 后端目录；令牌文件每行一个，不会写入结果。
.venv/Scripts/python.exe scripts/load_test.py --users 1 --tokens-file ../_work/load-tokens.txt --collect-metrics --label REAL_MODEL --output ../research/runs/load-1.json
.venv/Scripts/python.exe scripts/load_test.py --users 2 --tokens-file ../_work/load-tokens.txt --collect-metrics --label REAL_MODEL --output ../research/runs/load-2.json
.venv/Scripts/python.exe scripts/load_test.py --users 5 --tokens-file ../_work/load-tokens.txt --collect-metrics --label REAL_MODEL --output ../research/runs/load-5.json
```

每次记录首 token / 整轮 P50、P95、错误与降级比例、清理结果、HTTP 版本、API worker 的 CPU 时间和采样 RSS 峰值。默认首 token P95 目标为 3000ms，这只是可配置验收目标，不是已达成承诺。小批次分位数仅检查工具链，正式容量验收要在相同配置下多批重复并扩大样本。

资源采样只适用于单 worker 隔离环境，不代表整机、浏览器、ASR、Redis 或 MySQL 的总资源。不能边跑其他压力任务边把 CPU 结果当作纯模型链路占用。模型计数为应用发起的请求尝试，不含健康探测；成功返回的 provider usage 才计 token，流式模型不返回 usage 时标未知。费用不推算为 0，应另按服务账单和当时计价核对。

真实模型不可用时，保留真实错误，再用受控响应检查脚本、SSE 计时、错误闸门与自动清理。受控负载报告必须注明 CONTROLLED_STUB，不能用于宣称可承受相同数量的真实模型会话。

语音并发另测 1 路、2 路及第 3 路的忙碌提示；当前语音槽位上限为 2，第 3 路可预期返回忙碌，不能为了压测数字临时放宽资源保护。真实语音耗时需区分 ASR 首次预热、识别、模型回复和出声时间，不把无首 token 的超时填成正常延迟。

本轮真实模型抽查返回 HTTP 402，真实模型校准和并发耗时尚不能验收。见本轮验收记录；恢复上游可用状态后按上述同一命令重跑。
